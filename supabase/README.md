# Supabase

- `migrations/`: database setup, run in order in the Supabase SQL Editor (001 first). All have been run on the staging project. Each is safe to run again.
- `emails/`: sign-in email templates. Paste into Authentication, then Emails, then Templates (Confirm signup, Magic Link).
- `admin-queries.sql`: handy read-only queries (passes, refunds, A/B test results).
