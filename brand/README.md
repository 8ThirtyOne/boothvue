# BoothVue brand files

Logo and icon files for BoothVue. SVG scales to any size; PNG is for places that need a picture file.

## Colors
- Brand blue: `#2563eb` (icon square, buttons, "Vue" on light backgrounds)
- Light blue: `#4f8cff` ("Vue" on dark backgrounds)
- Ink: `#111722` (dark text)

## Type
- Wordmark: Bricolage Grotesque, weight 800. "Booth" in ink or white, "Vue" in blue.

## svg/
| File | What it is |
|---|---|
| `boothvue-icon.svg` | App icon: white mark on a rounded blue square |
| `boothvue-icon-square.svg` | Same, with square corners (for places that round the corners themselves) |
| `boothvue-mark-white.svg` / `-blue` / `-black` | The mark alone, no background |
| `boothvue-logo-on-light.svg` | Icon + wordmark for light backgrounds |
| `boothvue-logo-on-dark.svg` | Icon + wordmark for dark backgrounds |

The two logo SVGs keep the wordmark as live text, so they need the Bricolage Grotesque font to look right. Where the font may be missing, use the PNG versions.

## png/
All PNGs have a transparent background.
- `boothvue-icon-1024 / 512 / 192 / 180 / 64 / 32.png`: the app icon at common sizes
- `boothvue-icon-square-1024.png`: square-corner icon
- `boothvue-mark-white / blue / black-1024.png`: the mark alone
- `boothvue-logo-on-light-1520 / 760.png`, `boothvue-logo-on-dark-1520 / 760.png`: icon + wordmark
- `boothvue-mark-white-email-124.png`: the small white mark the emails use (copy of `img/logo-email.png`)
